## Cómo trabajo

- **Los datos primero:** reviso nulos, duplicados y fugas antes de modelar o graficar, y dejo escritos los límites de la información.
- **Cifras que se comprueban:** lo que afirmo sale de los datos y se verifica con código.
- **Con IA, y diciéndolo:** uso asistentes para programar más rápido; cada proyecto aclara qué herramientas intervinieron.
